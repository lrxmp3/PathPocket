# PathPocket changelog

## 1.0.6

The frozen scientific backend 0.3.0 and original GUI 1.0.6 are distributed with public examples, tests, bilingual documentation, and the replay entry point.

Maintenance fixes cover the trusted built-in NO_TARGETS GUI path, paths containing spaces, and automatic two-dimensional display of saved molecule records. Scientific algorithms, thresholds, generation parameters, model weights, and report definitions are unchanged. See `RELEASE_NOTES_v1.0.6.md` for scope and limitations.
